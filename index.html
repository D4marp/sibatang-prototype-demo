Pertahanan berlapis

Isolasi tenant

Peran saja tidak cukup: cek scope resource di backend dan RLS PostgreSQL. Role runtime bukan superuser / BYPASSRLS.

Anti-bocor data pribadi

Tanpa NIK / HP / QR / token / isi formulir di layar, laporan agregat, event publik, atau log. Log terstruktur dan ter-redaksi.

Atomik & teraudit

Slot, pembatalan, check-in, call-next: atomik, idempoten, diuji race. Audit ditulis dalam transaksi yang sama.

Sesi & login

Cookie HttpOnly + CSRF. Login staf OIDC (Authorization Code + PKCE), gerbang MFA, tanpa auto-provision.

Satu kontrak API

OpenAPI tunggal menghasilkan klien TS & Dart; error dan enum stabil; kompatibel dengan perangkat desktop terpasang.

Operasional

Self-hosted / privat, TLS, DB terbatas, backup terenkripsi teruji, perangkat site dapat dicabut.
